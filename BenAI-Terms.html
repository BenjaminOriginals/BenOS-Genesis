Article 4. Description of the Service

4.1

4.2

Where the Open Chat Add-On has previously been enabled upon a Device, the Third-Party Model may be loaded into the memory of that Device while BenOS is starting, in order that it be available without delay; no download occurs for that purpose.

Live information. Where the User requests information of a kind that is not incorporated within BenOS, including weather, definitions and encyclopedic facts, the Service may retrieve such information from one or more Third-Party Services, in which case the data described in clause 7.3 shall be transmitted.

Voice. Features by which the User speaks to the Service, or by which Output is read aloud, rely upon the speech-recognition and speech-synthesis facilities of the User’s web browser, which are provided by the publisher of that browser under that publisher’s own terms and not by the Company.

4.6

Live. Live is available only when the Model selected by the User is Lite or Essential, those being the Models that respond without a period of deliberation. Live is not available with Pro or Ultra, and while Ultra is selected the control for Live is replaced by the control for Agent Mode. A User who has selected Pro or Ultra and who wishes to use Live will be invited to select Essential, and Live shall not commence unless and until the User does so.

4.7

BenStudio. Within BenStudio, the Understand Models, without the Open Chat Add-On, may: (a) generate an application from a description given by the User, by adapting one of a set of applications incorporated within BenOS to the name, colours and other preferences that the User describes; (b) make changes to the User’s code that the User describes in ordinary words; (c) identify and correct errors in the User’s code, including errors reported by BenStudio when that code is executed; (d) add explanatory comments and stylistic improvements to the User’s code; and (e) describe what the User’s code does. Upon a change being applied, BenStudio executes the resulting code within its preview, which is isolated from BenOS, and the Service reports to the User any error then shown.

4.8

BenBrowser. Within BenBrowser, and upon the User’s request, the Service retrieves the text of the web page that the User has open, in accordance with clause 7.3, and the Understand Models may generate from that text a summary, a list of key points, a simplified explanation, a summary of any part of the page, and an answer to a question asked by the User, which answer consists of the sentence or sentences of the page that the Understand Models determine to be responsive, or of such particulars as the page discloses concerning itself, including its author, date of publication and length. Where a question is not answered by the page, the Service may answer it from the knowledge incorporated within BenOS in accordance with clause 4.3, save where the question concerns the subject of the page itself.

4.9

Open Chat within BenStudio and BenBrowser. Where the Open Chat Add-On is enabled, Output within BenStudio and BenBrowser may instead be written by the Third-Party Model, which in BenBrowser is provided with the passages of the page selected by the Understand Models. Where the User asks only that the appearance of the User’s page be changed, the Third-Party Model is asked to provide style rules alone, which are added after the User’s existing style rules and do not alter the User’s HTML or JavaScript. Any change to code written by the Third-Party Model is examined by BenStudio before it is displayed to the User; errors introduced by it may be corrected by the Understand Models, and any error that remains is disclosed to the User. Where the Open Chat Add-On cannot be loaded, is stopped by the User, or produces no usable Output, the Output of the Understand Models shall be displayed in its place.
