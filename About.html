About BenOS Genesis

BenOS Genesis is a high-performance, browser-based OS for productivity and creativity that can run in any modern browser. Built on HTML and JavaScript, BenOS Genesis offers an intuitive file manager, exclusive music on BenMusic, a great hub for research in the BenBrowser, an HTML editor with live preview in the BenStudio app, and amazing customization in Settings.
